🧹 Esborrar Dades

Eina de neteja per al final de curs

Esborra de manera segura totes les dades de les eines didàctiques

⚠️ Atenció: Acció irreversible

Aquesta pàgina permet esborrar permanentment totes les dades guardades al navegador per les eines didàctiques generades amb el Generador de Programació Didàctica.

Un cop esborrades, les dades NO es poden recuperar. Assegura't d'haver fet una còpia de seguretat si necessites conservar alguna informació.

📊 Estat actual de les dades

A continuació es mostren totes les dades detectades al teu navegador, agrupades per eina:

📚 Esborrar per eina

Si només vols esborrar les dades d'una eina concreta, utilitza aquests botons:

💣 Esborrar TOT

Aquest botó esborrarà totes les dades de totes les eines, incloent:

  • Totes les programacions, planificadors i fitxes
  • Tots els historials de versions
  • Tots els logs d'accions
  • Les dades compartides entre eines
  • La configuració del generador
  • La preferència d'idioma
⚠️ Última advertència

Abans de continuar, assegura't que:

  • Has fet còpia de seguretat de les dades importants
  • Els alumnes han esborrat les seves fitxes
  • Has esborrat els emails amb fitxes rebudes

🍪 Galetes (cookies)

Aquestes eines no utilitzen galetes. Totes les dades es guarden al localStorage del navegador.

Si vols, pots esborrar manualment les galetes d'aquest domini des de la configuració del teu navegador:

  • Chrome: Configuració → Privadesa → Galetes
  • Firefox: Preferències → Privadesa → Dades
  • Safari: Preferències → Privadesa → Gestionar dades
  • Edge: Configuració → Privadesa → Galetes
